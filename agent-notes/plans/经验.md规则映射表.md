## 本轮已落地的能力（与重叠/字段布局相关）

- **P0-a**：旋转/镜像后用反推-正向法重算字段坐标 + 文字角度归一化 + `do_not_autoplace` 跳过 + 镜像放置翻转 dx。见 [决策记录](../decisions/2026-08-01-反推正向法重算字段坐标.md)。
- **P0-b**：autoplace 的 `body_bbox` 改用真实 graphics bbox ∪ pin 包络（含 arc 三点近似），宽体 IC 不再被误判为窄体。
- **P1-c**：`autoPositionFields` 三态 `{false, true, auto}`，默认 `auto`，接入 `add_schematic_component` / `rotate_schematic_component` / `batch_add_components`；放置/旋转后自动 autoplace。
- **P1-a**：autoplace 碰撞失败时递增 clearance 重试（最多 4 次），仍失败则标记 `unresolved` 返回。
- **P1-b**：`find_overlapping_elements` 新增 `overlappingFields`（field-on-body / field-on-other-body / field-on-field），解析 `hide`（bare 与 `(hide yes)` 两种形式）跳过隐藏字段；明确边界声明不含 `hierarchical_label` / sheet pin。

## 待建规则（后续迭代）

1. **值缺失/占位检测**：`lint_schematic_cosmetic` 增加"Value 为空或仍为占位（如 `?`、`Device`）"的告警。
2. **电源网络命名一致性**：同一电源网络出现多个别名（`3V3`/`VCC33`/`P3V3`）时告警。
3. **去耦电容覆盖检查**：对每个 IC 的 VCC 引脚，检查邻域是否有 100nF 去耦电容。
4. **接口电路模板检查**：USB/I2C/SPI 接口是否含上拉/串联电阻/ESD。
5. **信号流向启发式**：`suggest_placement` 按"输入左、输出右、电源上、地下"排序。
