# Agent Notes

本文件夹专门用于存放 agent（AI 编程助手）与项目交互过程中产生的信息，包括迭代计划、进度跟踪、交互记录与决策记录。与 `docs/` 下面向用户的项目文档区分开，这里记录的是 agent 工作过程中的"工作笔记"。

## 目录结构

| 目录 | 用途 | 命名约定 |
| --- | --- | --- |
| `interactions/` | agent 与用户的交互会话记录、关键问答摘要 | `YYYY-MM-DD_<topic>.md` |
| `plans/` | 迭代计划、任务拆解、分阶段实施方案 | `YYYY-MM-DD_<feature>_plan.md` |
| `progress/` | 进度跟踪、完成情况、遗留事项 | `YYYY-MM-DD_<feature>_progress.md` 或 `STATUS.md` |
| `decisions/` | 重要技术决策、方案选型记录（ADR 风格） | `YYYY-MM-DD_<topic>_decision.md` |

## 写作规范

- 每条记录开头标注：日期、参与者、上下文。
- 计划类文件应包含：目标、任务清单（含状态）、风险、下一步。
- 进度类文件应包含：已完成、进行中、阻塞项、下一步。
- 决策类文件应包含：背景、可选方案、决策、理由、影响。
- 引用代码时使用相对路径与行号，避免绝对路径。

## 与其它目录的关系

- `docs/`：面向最终用户/开发者的项目文档（架构、指南、状态）。
- `agent-notes/`：agent 工作过程中的临时/迭代笔记，成熟稳定的内容可择机迁移到 `docs/`。
- `.github/`、`scripts/`：自动化与脚本，不在本目录范围内。
